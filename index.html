Authorized Use

Operates using your own Telegram account. Only fetch media from chats you are already a member of.

Official API Credentials

Uses official API ID and Hash from my.telegram.org. No exploits or unverified endpoints.

Local Session Storage

Native MTProto Speed

Feature Breakdown

Everything built into AshlynnTGDL

Engineered for maximum fetching performance, clean directory organization, and account longevity.

Flexible Login Options

Choose between existing Pyrogram session strings or interactive Phone + OTP + 2FA authentication.

Kurigram Async Engine

Built on Kurigram, an actively-maintained Pyrogram fork optimized for Python 3.9+ async pipelines.

4 Parallel Chunk Streams

Transfers each file using 4 concurrent chunk streams to eliminate bandwidth bottlenecks on large media.

Smart Folder System

Saves downloads to AshlynnTGDL/ with support for custom named sub-folders per message range.

On-the-Fly Renaming

Strip unwanted branding text or replace strings across an entire batch using replace="find"="with".

Live Progress Bar

Displays live percentage, transfer speed in MB/s, transferred bytes, and estimated time remaining.

FloodWait Sleep Handling

Detects Telegram rate limit signals automatically and pauses for the exact duration requested.

Text Message Backup

Text-only messages in a range are automatically exported into cleanly formatted .txt files.

Account Safety Pacing

Three-tiered cooldown pauses (1.5s per file, 6s per 10 files, 20s per 50 files) to reduce account throttling risk.

Protection Architecture

Built-in account safety & throttle pacing

To mitigate Telegram API throttling and protect account health during batch operations, AshlynnTGDL implements automated tiered sleep intervals.

Inter-file Delay 1.5s pause
Every 10 Files Cooldown +6s pause
Every 50 Files Safety Break +20s pause
FloodWait Response Exact Telegram sleep

Responsible Usage Guidelines

  • Use personal credentials: Register your own API ID and API HASH at my.telegram.org.
  • Keep ashlynn_config.txt private: It contains your active Telegram session string. Never commit it to git.
  • Avoid excessive daily volume: Fetching tens of thousands of files continuously may cause Telegram rate limits.
